Turborel, on Kubernetes

Helm charts for the relational database written in Rust. Add the repository, install a chart, keep its values in git.

Add the repository

This page is a Helm repository: its index.yaml lists every chart and version, each packaged as a GitHub release of turborel/charts.

helm repo add turborel https://charts.turborel.com
helm repo update
helm search repo turborel

The charts

turborel

turboreld, the server, as one StatefulSet: its database on a volume of its own, a Service clients connect to on port 7422, and the server's settings passed as values.

helm install turborel turborel/turborel \
  --namespace turborel --create-namespace
